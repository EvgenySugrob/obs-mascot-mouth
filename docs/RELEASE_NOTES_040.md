## What's new

- Added automatic speaking bounce driven by microphone volume.
- Added squash and stretch on speech peaks.
- Added a subtle voice-reactive tilt.
- Added optional idle breathing.
- Added separate controls for every animation effect.
- No additional PNG files are required.

## Requirements

- Windows x64
- OBS Studio 32.1.2

## Installation

1. Close OBS Studio.
2. Extract the archive into the OBS Studio installation directory.
3. Start OBS Studio.
4. Open the Mascot Mouth source properties.
5. Adjust the animation settings if needed.

Existing scenes and v0.3.0 image settings remain compatible.
