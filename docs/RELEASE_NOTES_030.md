# Mascot Mouth v0.3.0

## What's new

- Added half-open and half-open blink image slots
- Added three mouth levels driven by microphone volume
- Added configurable wide-open threshold
- Added configurable microphone-level smoothing
- Added subtle vertical movement and scale while speaking
- Added fallback support for incomplete image sets

## Requirements

- Windows x64
- OBS Studio 32.1.2

## Installation

1. Close OBS Studio.
2. Extract the `obs-mascot-mouth` folder to
   `C:\ProgramData\obs-studio\plugins`.
3. Start OBS Studio.
4. Open the `Mascot Mouth` source properties and select the new images.
